# The console knows things the documentation does not

Generated by RFC 0005-bis phase 7. **A work list, not documentation** —
`internal/` is `srcExclude`d from the build.

`ui/src/config/registryTypes.ts` renders the Setup Guide at `/setup`, and
`docs/registries/<id>.md` documents the same setup for everyone who never opens
the console. Nothing had ever compared them.
`ui/src/config/registryTypes.docs.test.ts` now does, and its first run found
**37 snippets whose lines appear in the console and nowhere in the
documentation**.

These are not formatting differences — the normaliser masks tokens, hosts and
registry names precisely so that agreement is not reported as drift. They are
things a reader of the site cannot learn: how to point VSCodium's extension
gallery at BatleHub, the `mise` URL replacements that intercept downloads, the
generic mirror's environment variables.

Writing them up is content authoring, which RFC 0005-bis explicitly does not do
(§3, non-goals). The test is pinned at 37 so the number can only go down; each
one fixed is one line removed from the pin.

RFC 0005-bis O2 asks which way the eventual generation should run. This report
is the evidence: the console is systematically the richer side.
