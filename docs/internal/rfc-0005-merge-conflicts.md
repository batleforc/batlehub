# RFC 0005 — the four duplicated documents, and where the two copies disagree

Generated by phase 5. **This file is a work list, not documentation**: it lives
under `docs/internal/` and is `srcExclude`d from the build (RFC 0005 §6.7).

Four documents were maintained in two places. Nobody decided they should
differ — CLAUDE.md stated that `docs/` was copied into the site, and it never
was, so the second copy felt like a mirror while it was a fork. RFC 0005 Q5
settled which copy is canonical:

| Document | Canonical | Why |
| --- | --- | --- |
| `access-control` | the site's `guide/` copy | user-facing guide, maintained against readers |
| `sbom` | the site's `guide/` copy | same |
| `high-availability` | the site's `guide/` copy | same |
| `roadmap` | `ROADMAP.md` at the repo root | a project artifact that happens to be worth publishing; the published page is now generated from it (`task docs:roadmap`) |

The RFC does **not** pick winners line by line — that is content review, and
doing it silently during a move is how a merge loses a paragraph nobody notices
for a year. The diffs below are what a reader of the repo was being told and a
reader of the site was not, and the reverse. Each hunk needs one of three
answers: the site's copy is right, the repo's copy carried a fact worth folding
in, or both are stale.

Read the diffs as `-` = the deleted `docs/` copy, `+` = the surviving published
copy.
